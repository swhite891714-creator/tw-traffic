# 鏡頭即時翻譯（線上版）使用說明

網址：https://swhite891714-creator.github.io/tw-traffic/lens/

## 第一次使用

1. 手機打開上面的網址（iPhone 用 Safari、Android 用 Chrome）。
2. 拍照或選一張照片 → 按「整張翻譯」。
3. 會跳出「設定 Claude API 金鑰」視窗，貼上金鑰按「儲存」，就會開始翻譯。
   - 金鑰取得：用電腦打開 https://console.anthropic.com → 登入 →「API Keys」→「Create Key」→ 複製 `sk-ant-` 開頭的整串。
   - 帳號要先在「Billing」儲值，翻譯依用量計費。
   - 金鑰只存在這支手機的瀏覽器裡，只會送到 Claude 官方網址。
4. 加到主畫面，之後就像 App 一樣：
   - iPhone：Safari →「分享」→「加入主畫面」
   - Android：Chrome →「⋮」→「加到主畫面」

## 功能（和 Claude 裡的版本一樣）

- 照片翻譯：去掉原文，把譯文照原本的位置、大小、顏色排回去，並修補背景。
- 價格換算：選要換成的幣別；「只換價格」只改價格。
- 選範圍、轉正：拍歪了可以自動拉正或手動調角度。
- 語音翻譯：按「🎙 語音翻譯」→ 錄下對方說話 → 顯示中文、重點和建議回答；你也可以打字或錄音回話，翻成對方的語言並唸出來。第一次使用語音會下載約 100MB 的辨識模型（建議連 Wi-Fi），之後存在手機裡。

## 常見問題

- **金鑰不正確**：會自動再跳出金鑰視窗，重新貼上即可。標題列右邊的「金鑰」按鈕可以隨時更換或刪除。
- **額度不足**：到 console.anthropic.com 的 Billing 儲值。
- **想在別支手機用**：打開同一個網址，貼上金鑰（金鑰等於付款權限，只給信任的人）。

## 檔案說明（都有中文註解）

- `index.html`：畫面與主程式（拍照、選範圍、去字排版、價格換算）
- `claude-api.js`：用你的金鑰連到 Claude（取代 claude.ai 內建的連線）
- `talk.js`：語音翻譯對話
- `stt.js`：在手機上把錄音轉成文字
- `w/`：語音辨識模型檔案
